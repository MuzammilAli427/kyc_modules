=============================GeoIP Redirect (ODOO 12.0)================================<br/>
> Auto-detect IP address of the customer.<br/>
> Auto-redirect to store as per the customer's location.<br/>
> Redirect customers to appropriate store or custom URL.<br/>
> Display content on the website as per customer's language.<br/>
> Automatically switch currency based on customer's location.<br/>
> Display price of products as per customer's local currency.<br/>
> Restrict visitors of particular IP addresses/countries.<br/>
> Ignore search engines and user agents.<br/>
> Customers will have the flexibility to change store manually too.<br/>
> Admin has flexibility to redirect visitors for each visit or only for the first one.<br/>
